# 安全、授权与边界

NebulaIL2CPP 仅面向安全研究、兼容性测试、自有 Unity 项目或已取得明确授权的应用测试。使用者必须确认目标应用许可、服务条款、测试范围、数据处理要求和所在地法律。

项目不提供通用注入器、签名绕过、完整性校验绕过、Root 工具、游戏资源或第三方应用数据。本文档不是绕过授权、反篡改或安全控制的指南。

## 最小化风险实践

1. 使用隔离的测试设备、模拟器和测试账号。
2. 保存原始 APK、构建哈希和修改记录。
3. 仅启用测试需要的 Mod，并为失败路径提供安全返回。
4. 不收集无关用户数据，不把日志上传到公共位置。
5. 发布前审阅第三方依赖许可证和目标应用许可。

Hook、字段写入和对象创建都可能导致进程崩溃或数据损坏。请在非生产环境验证，并为每次实验准备可回滚的原始产物。
