# 第三方依赖

Nebula 使用 Git submodule 管理第三方源代码。发布或分发构建产物前，请阅读原项目 `NOTICE-THIRD_PARTY.md` 及各依赖目录中的许可证文件。

| 依赖 | 固定版本或提交 | 用途 | 许可证 |
| --- | --- | --- | --- |
| Dobby | `b0176de574104726bb68dff3b77ee666300fc338` | ARM64 Inline Hook | Apache-2.0 |
| Dear ImGui | `v1.92.5` | Overlay UI | MIT |
| nlohmann/json | `v3.12.0` | JSON 配置 | MIT |

第三方许可证不等同于 NebulaIL2CPP 主项目许可证；正式公开发布前请确认主项目授权声明。
